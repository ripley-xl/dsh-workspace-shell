## 联调中修复的问题

- 远端状态插件入口必须显式指向 `index.js`，目录导入会被 Node ESM 拒绝。
- 远端运行包必须包含 pnpm，并把运行包 `bin` 放进 Host 的 PATH。
- 存储单元名从后端不接受的 `ssh-remote` 改为 `ssh_remote`。
- 无版本的插件 spec 与独立 version 字段会合成精确安装版本；冲突会报错。
- 已安装运行包复用同时检查版本、构建和安装回执摘要。
