# SSH 工作区组件

用户已确认以下范围，实施时保留新建工作区的现有功能。

## 组件与入口

- 工作区框架 bundle 包含框架组件与 SSH Remote 组件，SSH 默认开启。
- 使用 DSH 插件详情的组件开关，不另设总开关。每条连接原有的自动连接开关保持独立。
- SSH 组件向框架注册 launcher 界面、请求与状态订阅；关闭组件时撤销注册。框架在没有 SSH 组件时仍可使用本地 Web/TUI。
- 删除旧 SSH Remote 管理页、侧栏入口、底部 SSH 工作区入口及旧页面的视图状态管理。
- 保留新建工作区的连接、设置、转发、Host 列表、新建页签、停止及全部本机功能。必要的认证确认由组件弹窗处理；版本升级自动执行。

## 生命周期

- 关闭组件时取消待完成操作、断开 SSH 和本地转发、释放远程 Guest。
- 已打开的远程页签保留原位置与身份，显示组件已停用；不保留可再次使用的旧认证 URL。
- 重新开启后可重试页签，按原实例接入；原实例不可用则报告错误，不自动启动替代实例。
- 保留连接记录、每条连接的自动连接设置和远端持久 Host。关闭组件不能调用停止远端 Host 的接口。
- 注册和注销必须幂等，旧注册的迟到响应不能改变新注册状态。
- 自动重连仅遵循已有连接设置；默认开启组件不等于自动连接所有主机。

## 窗口拖动

- Native 页签栏的空白区域全部可拖动窗口，包括页签右侧剩余空间。
- 页签排序、页签关闭、加号及其他按钮保持非窗口拖动区域。
- 验证本地、远程及 launcher 激活时的窗口拖动；不修改 DSH 应用包。

## 验收

- 新建工作区左侧 SSH 来源状态点与真实连接状态一致，连接时绿色、断开时灰色；页签栏同步更新。

- 组件默认开启、单独关闭、重开和快速重复切换。
- 关闭组件保留远程页签并释放资源；本地视图和远端 Host 不受影响。
- 组件关闭期间新建工作区不发出 SSH 请求；重开可接入原实例。
- 未知主机密钥、口令均需用户决定；版本升级自动对齐本机版本；秘密不进入持久状态或日志。
- 旧导航入口不存在，新建工作区现有控件和中英文文案保持可用。
- Native 真实鼠标拖动验证窗口位移，并回归页签切换、排序和按钮点击。
