# SSH Remote 集成

SSH Remote 是 `dsh-workspace-shell` 的一部分：同一个包提供工作区页签和 SSH 远程工作区，安装一个包即包含全部功能。

## 入口

- 工作区窗口的页签栏、launcher 和 SSH 远程页签来自同一个插件。
- SSH 功能向框架注册 launcher 界面、请求与状态订阅；框架没有 SSH 连接时，本地 Web 和 TUI 照常可用。
- 每条连接有独立的自动连接开关，默认不自动连接未启用的主机。
- 新建工作区的连接、设置、端口转发、Host 列表、新建页签、停止以及全部本机功能都在插件内完成。认证和升级确认由插件弹窗处理。

## 生命周期

- 断开连接时取消待完成操作、断开 SSH 和本地转发、释放远程 Guest。
- 已打开的远程页签保留位置与身份，显示为离线；不保留可再次使用的旧认证 URL。
- 重新连接后可按原实例接入；原实例不可用则报告错误，不自动启动替代实例。
- 保留连接记录、每条连接的自动连接设置和远端持久 Host。
- 注册和订阅必须幂等，旧请求的迟到响应不能改变当前状态。

## 窗口拖动

- Native 页签栏的空白区域可拖动窗口，包括页签右侧剩余空间。
- 页签排序、页签关闭、加号及其他按钮不参与窗口拖动。
- 不修改 DSH 应用包。

## 状态

- 新建工作区左侧 SSH 来源状态点与真实连接状态一致：连接时绿色，断开时灰色，页签栏同步更新。
- 未知主机密钥、口令和升级确认均需用户决定；秘密不进入持久状态或日志。
