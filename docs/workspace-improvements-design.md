# 工作区改进与验收

日期：2026-11-04。用户已确认以下范围并授权实施。

## 本次范围

### SSH 组件化

- 工作区框架 bundle 包含 SSH Remote 组件，默认开启，使用插件详情中的原生组件开关。
- 框架、本地运行时、会话登记和导航是核心，不提供独立组件开关；详情只列出 SSH 子组件。
- 删除旧 SSH Remote 独立管理页、侧栏入口和底部重复入口。
- 保留新建工作区中的全部功能：本机 Web/TUI、SSH 连接、新增连接、自动连接设置、连接设置、端口转发、Host 列表、新建页签和停止。
- SSH Host 的打开入口只保留“新建页签”，不恢复已移除的重复入口。
- 停用组件时取消待完成操作，释放 SSH 连接、本地转发和远程 Guest；保留远程页签记录、连接配置及远端持久 Host。
- 停用的远程页签显示“SSH 组件已停用”。重开后可重试，必须接入原实例；原实例不可用时报告错误，不自动启动替代实例。
- 本机工作区与 SSH 组件开关相互独立，认证、升级及同步结果确认仍保留。

详细约束见 [SSH 工作区组件](ssh-workspace-component-design.md)。

### 页签栏拖动

- Native 页签栏所有空白区域都能拖动窗口，包含页签右侧剩余空间。
- 页签本体保留排序手势，关闭按钮、加号及其他按钮继续响应点击。
- 本地、远程、新建工作区激活时分别验证真实窗口位移，不以 CSS 断言代替实机验收。

### SSH 连接状态点

- 新建工作区左侧 SSH 来源状态点与真实连接状态一致：已连接为绿色，未连接为灰色。
- 连接状态变化及时反映到来源列表与页签栏，不能因旧请求完成而恢复过期状态。
- 原有 SSH 设置字段解析修复必须保留，不暴露凭据或认证地址。

### 发送失败与草稿跳转

- 保留原生列表、历史和输入框，不再增加侧栏图标或单独只读预览。
- 仅在实际返回 `session/writer-held` 时，在输入区显示占用提示及“前往页签 / 打开页签”。
- 点击后定位正确 Host 的同一会话，把本次失败的文字追加到目标输入框，用户自行确认发送。
- 保留来源后续修改和目标已有草稿，不自动发送；附件留在来源，提示明确说明。
- 无可复用页签时直接接入指定的现有 Host，不再加一层确认框。不得启动替代 Host、强制接管或丢失草稿。
- 原 Host 退出后，当前 Host 可按 DSH 原生流程继续。登记未知不限制用户发送，也不表示写锁已释放。
- 第一版覆盖本机 Desktop 与 Web Host；不合并隔离存储，不扩展到 SSH 跨机器会话。

详细状态、接口边界及失败处理见 [会话运行位置与跨页签跳转](session-host-navigation-design.md)。

## 实施约束

- 只修改自有插件、脚本及文档，不改 DSH 源码、Electron 应用包或其他代理负责的 Web profile。
- 核实宿主实际提供的发送结果、会话状态、草稿及导航接口；接口不足时报告具体缺口，不伪造定位成功。
- 保留现有用户配置与运行中的 Host。需要重启 Desktop 时另行说明影响并征求同意。
- 每次发布先运行相关测试，再完整回归；安装备份和验收结果存放于独立发布目录。
